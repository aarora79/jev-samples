pr-triage: from a pull request to one instruction

A pull request
title, description, file list, diff, and its check runs
Pre-triage: plain rules, no model
Is it a draft? Is a check failing? Is a check still running?
any of them yes
Stop. Report the state.
draft · ci-failing · ci-pending
No model call, nothing spent, nothing to review yet.
all of them no
the only model call
One Jev call, eleven questions
9 weighted feed the numbers:
blast radius, security surface, has tests, and six more
2 labels are reported, never scored:
what kind of change it is, and what to check first
The nine become a pair
effortmean of all nine
how long to read
consequencemax of four
what breaks if wrong
The pair picks one route, and the route is the instruction
RouteWhat the repo owner does
green-is-enoughmerge it on a green tick, nobody needs to read it
tests-are-enoughmerge it once a test covers the change
ai-review-is-enoughrun an AI review; if it finds nothing, merge it
human-requiredput it in front of a person before it merges
human-plus-authora person reads it with the author walking them through
